# Desktop
I am developing a Java desktop application called
"Soya's Medium Clinic Information System".

Technology requirements:
- Java
- Java Swing for the GUI
- MySQL for the database
- JDBC for database connectivity
- MVC architecture
- The application should be suitable for a small private clinic.

Main users:
- Admin
- Receptionist
- Physician
- Laboratory Technician
- Pharmacist

The system should include:
1. Login and authentication
2. Patient registration and management
3. Appointment management
4. Vital signs
5. Diagnosis
6. Treatment
7. Laboratory requests and results
8. Prescription
9. Pharmacy dispensing
10. User management
11. Reports

Do not generate the whole application at once.
First create the recommended project folder/package structure
and explain what each package will contain.
